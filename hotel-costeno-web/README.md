# Hotel Costeño de Colima — Website Package

Paquete completo listo para producción o para enviar a Claude Design para refinamiento.

## Contenido

```
hotel-costeno-web/
├── index.html          ← Sitio web completo (HTML + CSS + JS en un archivo)
├── design-brief.md     ← Brief completo para Claude Design
└── README.md           ← Este archivo
```

## Abrir el sitio

Simplemente abre `index.html` en cualquier navegador moderno. No requiere servidor ni dependencias instaladas.

## Dependencias externas (CDN)
- Google Fonts: Playfair Display, Lato, Cormorant Garamond
- Font Awesome 6.5 (iconos)
- Imágenes placeholder: Unsplash (reemplazar con fotos reales del hotel)
